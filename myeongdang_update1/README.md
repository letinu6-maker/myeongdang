# 명당발견

외국인 관광객 숙소, 서울 어느 구에서 시작해야 본전을 찾을까?

외국인관광 도시민박업(에어비앤비) 신규 호스트를 위한 자치구별 입지 비교·손익분기 계산 서비스입니다.

> 작성 중입니다. 설치·실행 방법은 개발이 진행되면서 채워집니다.

## 팀
- 박준영: 데이터 수집·정리·결합, 건수 검증
- 김태현: API 서버, 화면, 예외 처리, 테스트, README

## 완료 기준: 손으로 계산한 예시
서비스가 맞게 동작하는지 아래 숫자로 확인합니다. API(`/simulate`, `/rank`)와 화면 모두 같은 값이 나와야 합니다.

**손익분기 계산**
- 입력: 1박 요금 80,000원, 예상 가동률 60%, 월세 900,000원, 월 기타 비용 300,000원
- 월 비용 = 900,000 + 300,000 = 1,200,000원
- 손익분기 예약일수 = 1,200,000 / 80,000 = **15일**
- 예상 월 손익 = 80,000 x 30 x 0.6 - 1,200,000 = 1,440,000 - 1,200,000 = **240,000원**

**입지 지표 (한 자치구)**
- 입력: 야간 단기외국인 1,200명, 주간 단기외국인 3,000명, 영업 중 객실 60실, 야간 가중치 0.7
- 수요 = 0.7 x 1,200 + 0.3 x 3,000 = 840 + 900 = **1,740**
- 객실당 수요 = 1,740 / 60 = **29.0**
