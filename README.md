# 명당발견 — 외국인 관광객 숙소, 서울 어느 구에서 시작해야 본전을 찾을까?

**의사결정 질문:** 외국인 관광객 숙소를 서울 어느 자치구에서 시작하는 것이 유리하고, 내 예상 요금·가동률이면 손익분기를 넘길 수 있는가?
**사용자:** 외국인관광 도시민박업 등록을 준비하는 예비 에어비앤비 호스트(개인 사업자)
**팀:** 박준영(데이터 담당) · 김태현(서비스 담당)

서비스는 두 가지를 합니다.
1. **입지 비교:** 서울 25개 자치구를 외국인 숙박 수요와 경쟁 업소 수로 비교해 순위를 보여 줍니다.
2. **손익분기 계산:** 1박 요금·가동률·월세·기타 비용을 넣으면 한 달에 최소 며칠 예약돼야 본전인지와 예상 월 손익을 보여 줍니다.

## 4. API

| 엔드포인트 | 설명 | 파라미터 |
|---|---|---|
| `GET /health` | 서버 상태, 사용 중인 데이터(processed/sample), 기준 시점 | 없음 |
| `GET /districts` | 서울 25개 자치구 코드·이름 | 없음 |
| `GET /rank` | 조건별 자치구 순위 | `night_weight`(0~1, 기본 0.7), `min_listings`(0 이상, 기본 50), `max_listings`(선택, 0 이상), `districts`(선택, 쉼표 구분 코드), `top_n`(1~25, 기본 5) |
| `GET /simulate` | 손익분기·예상 월 손익 | `price`(1~2,000,000원), `occupancy_pct`(0~100), `monthly_rent`(0~10,000,000원), `other_cost`(0 이상, 기본 0), `sgg_code`(선택) |

**예외 처리:** 범위 밖 값 → 400 + 한국어 안내 / 없는 자치구 코드 → 400 / 최소 업소 수 > 최대 업소 수 → 400 / 결과 0건 → 200 + 안내 / 데이터 파일 없음 → 503. 어떤 경우에도 서버와 화면은 멈추지 않습니다.

응답 형식: `{"ok": true, "message": "", "data_source": "processed|sample", "data_as_of": "...", "results": [...], "excluded": [...]}`
`excluded`는 업소 수가 `min_listings` 미만이라 순위에서 빠진 "검증 부족 시장"입니다.

## 5. 계산 방법 (`src/scoring.py`)

- 수요 = 야간 가중치 × 야간 단기외국인 + (1 − 야간 가중치) × 주간 단기외국인
- 업소당 수요 = 수요 ÷ 영업 중 업소 수 (0곳이면 ÷1, "경쟁 없음" 표시)
- 업소가 `min_listings`(기본 50) 미만인 구는 순위에서 빼고 "검증 부족 시장"으로 따로 표시
- 점수 = 0.6 × z(업소당 수요) + 0.4 × z(수요) — **필터 후 남은 구만으로** 표준화(모표준편차)
- ⚠ 미등록 숙소 주의: 주간 단기외국인이 25개 구 중 상위 25%인 구
- 손익분기 예약일수 = (월세 + 기타 비용) ÷ 1박 요금 (올림, 30 초과면 "한 달 내내 차도 적자")
- 예상 월 손익 = 1박 요금 × 30 × 가동률 − (월세 + 기타 비용)

## 6. 완료 기준 — 손계산 예시

| 구분 | 입력 | 손으로 계산 |
|---|---|---|
| 손익분기 | 1박 80,000원 · 가동률 60% · 월세 900,000원 · 기타 300,000원 | 1,200,000 ÷ 80,000 = **15일** / 80,000 × 30 × 0.6 − 1,200,000 = **240,000원** |
| 입지 지표 | 야간 1,200명 · 주간 3,000명 · 업소 60곳 · 가중치 0.7 | 0.7 × 1,200 + 0.3 × 3,000 = **1,740** / 1,740 ÷ 60 = **29.0** |

테스트 실행: `pytest`

## 11. 경영적 시사점과 한계

*(A와 함께 작성 예정)*
- 1박 요금·가동률·월세는 공개 데이터가 없어 사용자 입력 가정값입니다.
- 미등록 숙소와 공유숙박 실증특례 숙소는 인허가 데이터에 없어, 경쟁은 등록 업소 기준 최소치입니다. 호텔과의 경쟁은 반영하지 않았습니다.
- 생활인구는 통신 데이터 기반 추정치입니다.
